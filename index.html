Lanskap maps service

Siapa menyediakan apa di dunia maps API, dan di mana bisa dicoba.

Peta lanskap penyedia layanan peta saat ini: dari big tech, spesialis data, platform developer, GIS enterprise, open source, sampai pemain lokal Indonesia. Semua link playground sudah dicek.

Coba playground Lihat matriks

    01Siapa saja pemainnya

    Enam kelompok penyedia, beda cara main.

    Klik nama penyedia untuk melihat detailnya.

    02Apa yang mereka tawarkan

    22 kategori layanan, empat kelompok besar.

    Pilih kelompok. Tiap kartu menunjukkan siapa yang menyediakan layanan itu secara penuh (✓), dan berapa yang hanya sebagian (◐).

    03Matriks kemampuan

    Bandingkan berdampingan.

    ✓ ada, ◐ sebagian atau bersyarat, – tidak ada, cek = belum terverifikasi. Skor: ✓ = 1, ◐ = 0,5. Klik judul kolom untuk mengurutkan.

    04Coba sendiri

    link playground, dikelompokkan per layanan.

    Mulai dari yang tanpa akun: Valhalla, OSRM, GraphHopper Maps, Nominatim, Photon, Maputnik, dan Overture Explorer.

    05Playground langsung

    Bandingkan penyedia langsung di sini.

    Geocoding, reverse geocoding, rute, dan isochrone dari beberapa penyedia sekaligus, di peta yang sama. Penyedia tanpa key langsung jalan; penyedia lain aktif setelah kamu menempelkan API key sendiri.

    Pencarian hanya dijalankan saat tombol ditekan (tanpa autocomplete per ketikan), sesuai kebijakan pemakaian Nominatim.

    Klik di mana saja pada peta. Titik itu akan di-reverse geocode oleh semua penyedia yang aktif.

    Belum ada titik.

    Klik peta untuk titik A lalu titik B, atau pakai preset.

    A: – · B: –

    Klik peta untuk titik pusat, pilih waktu tempuh, lalu hitung area jangkauan (mobil).

    Pusat: Braga, Bandung (bawaan)

    Penyedia untuk mode ini

    Kunci API (opsional)

    Key disimpan hanya di browser kamu (localStorage) dan dikirim langsung dari browser ke API penyedia. Tidak ada server perantara. Pakai key yang dibatasi domain/referrer, dan hapus kapan saja dengan tombol di bawah. Server demo publik gratis (Nominatim, Photon, OSRM, Valhalla FOSSGIS, OpenFreeMap, tile OSM) punya batas fair use: jangan dipakai untuk beban berat atau otomatis.
